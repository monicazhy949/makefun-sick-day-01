A one-line sick-day excuse that stays just believable enough to work: it opens with an ordinary sneeze, escalates to a thrown-out back and a doctor's orders, then lands the punchline on "definitely no spreadsheets" — the one restriction no real doctor would prescribe. Running `python3 main.py` prints the excuse and also writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
